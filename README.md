# ханикаке — лендинг «Макарон на заказ во Владивостоке»

Одностраничный сайт для кондитерской макарон **hanni_cake_** (Анжелика, Владивосток). Чистый HTML + CSS + JS, без сборщиков и зависимостей — готов к публикации на любом хостинге (GitHub Pages, Netlify, Beget, Timeweb и т. п.).

## Структура

```
index.html          — страница (11 блоков, schema.org Bakery + FAQPage + WebSite)
css/style.css       — стили, адаптив 320–1920 px
js/main.js          — бургер-меню, вкладки вкусов, конструктор коробочки, слайдер отзывов, ленивые видео и карта
img/                — изображения WebP + JPG-фолбэк (600 и 1200 px), логотип, OG-картинка
video/              — 4 коротких ролика H.264 без звука + постеры
robots.txt, sitemap.xml, llms.txt, site.webmanifest — SEO и GEO (AI-поиск)
seo-keywords.md     — семантическое ядро и план продвижения
.htaccess           — сжатие и кэширование (для Apache)
```

## Блоки
1. Первый экран — H1 «макарон на заказ во владивостоке», коробочка с логотипом, видео с дубайским макарон
2. Макарон-мишки — фирменная позиция
3. Вкусы сезона — вкладки: ассорти / осень / ко дню папы
4. Конструктор коробочки — выбор 4/8/12/16 шт, раскладка вкусов, подсчёт цены, копирование заказа и переход в директ
5. Прайс — три «билетика» в цвете сторис
6. Как оформить заказ — 4 шага
7. Кто печёт — история Анжелики и конвектомат
8. Галерея
9. Отзывы — слайдер со свайпом
10. Частые вопросы (размечены для расширенных сниппетов)
11. Откуда забирать — самовывоз с Патрокла, доставка, Яндекс Карта (подгружается при прокрутке)

## Перед публикацией
- Заменить `https://hanni-cake.ru/` на реальный домен: `index.html` (canonical, og:*, schema), `robots.txt`, `sitemap.xml`, `llms.txt`.
- Если у кондитера есть точный адрес самовывоза — заменить параметр `text=` у карты в блоке `#map` и `streetAddress` в schema.
- Ссылка заказа ведёт в директ `https://ig.me/m/hanni_cake_`. Если в шапке профиля стоит форма (Taplink, Google Form и т. п.) — замените ссылку в `index.html` и константу `IG_DM` в `js/main.js`.
- Шрифты (Unbounded, Manrope, Caveat) подключены из Google Fonts. Чтобы не зависеть от Google, скачайте их через google-webfonts-helper, положите в `fonts/` и замените `<link>` на `@font-face`.

## Совместимость
Safari iOS 12+, Chrome/Android 7+, Firefox, Edge, Яндекс Браузер. Учтены safe-area для iPhone с вырезом, `100dvh`, отключение анимаций при `prefers-reduced-motion`, фолбэк копирования в буфер для старых браузеров.
